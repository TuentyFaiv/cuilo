En este tutorial agregas un átomo `status-badge` del pack oficial `ui` a un proyecto de React. Después lo editas, ves lo que cuilo registra de él y deshaces el cambio. Necesitas cuilo en tu `PATH`; consulta [Instalación](/es-mx/install/).

## Prepara un proyecto

Usa un proyecto de React y TypeScript que ya tengas, o crea uno vacío. En este tutorial no se instala nada. cuilo solo lee `package.json`.

<Steps>

1. Crea una carpeta y entra en ella:

   ```sh
   mkdir my-app && cd my-app
   ```

2. Crea `package.json`:

   ```json title="package.json"
   {
   	"dependencies": { "react": "19.0.0" },
   	"devDependencies": { "typescript": "6.0.0" }
   }
   ```

3. Revisa lo que detecta cuilo:

   ```sh
   cuilo detect
   ```

   ```text
   {
     "stack": {
       "framework": [
         "react"
       ],
       "language": [
         "typescript"
       ],
       "runtime": [
         "node"
       ],
       "package_manager": [
         "npm"
       ]
     },
     "env": []
   }
   ```

</Steps>

La variante de React del pack `ui` necesita tanto `react` como `typescript`. Sin `typescript` en `package.json` o un `tsconfig.json`, cuilo avisa que ninguna variante coincide. Consulta [Detección del stack](/es-mx/guides/stack-detection/).

## Revisa el plan

Pide el plan sin escribir nada:

```sh
cuilo add ui/atom status-badge --dry-run
```

```text
add ui/atom
  create  src/ui/atoms/status-badge/status-badge.module.css
  create  src/ui/atoms/status-badge/status-badge.tsx
  create  src/ui/atoms/status-badge/index.ts
```

Así se lee:

- `ui/atom` es el pack y la pieza. `status-badge` es la entrada `name` de la pieza. También puedes escribirlo como `StatusBadge`.
- Los archivos van a `src/ui/atoms/`, la carpeta por defecto de la pieza.
- El plan trae un módulo CSS porque el proyecto no usa Tailwind.
- El plan no trae archivo de pruebas porque el proyecto no tiene Vitest. Agrega `-i tests=true` para obtener uno. Entonces el plan también lista los paquetes de pruebas que hay que agregar.

## Aplícalo

Corre el mismo comando sin `--dry-run`. cuilo vuelve a mostrar el plan y pregunta antes de escribir:

```sh
cuilo add ui/atom status-badge
```

```text
add ui/atom
  create  src/ui/atoms/status-badge/status-badge.module.css
  create  src/ui/atoms/status-badge/status-badge.tsx
  create  src/ui/atoms/status-badge/index.ts
Apply these changes? [y/N] y
Applied transaction 1 (3 file(s)). Undo it with `cuilo undo`.
```

El componente es código normal y puedes editarlo:

```tsx title="src/ui/atoms/status-badge/status-badge.tsx"
import type { ComponentProps } from "react";

import styles from "./status-badge.module.css";

export type StatusBadgeTone = "neutral" | "accent";

export type StatusBadgeProps = ComponentProps<"span"> & {
	/** Visual emphasis. */
	tone?: StatusBadgeTone;
};

const classes = styles;

/** The smallest UI building block: an inline, label-sized element. */
export function StatusBadge({ tone = "neutral", className, ...props }: StatusBadgeProps) {
	return <span {...props} data-tone={tone} className={[classes.root, className].filter(Boolean).join(" ")} />;
}
```

cuilo también creó dos cosas junto a `package.json`:

- `cuilo.lock`, que va en tus commits. Fija el pack y registra la pieza:

  ```toml title="cuilo.lock"
  # Generated by cuilo. Commit this file; do not edit it by hand.

  version = 1

  [[pack]]
  name = "ui"
  version = "0.2.0"
  source = "official:ui"
  digest = "sha256:659daddc6c30ad71639fbda1bee3051eefa532680676fd546cbfaed8fef47cf4"

  [[instance]]
  id = "atom-d479162786"
  pack = "ui"
  pack_version = "0.2.0"
  piece = "atom"
  variant = "react"
  target = "src/ui/atoms"
  ```

  Después vienen el stack y las entradas con los que se generó la pieza, y una tabla `[[instance.file]]` por archivo con el hash de lo que escribió cuilo.

- `.cuilo/`, el historial local que usa `cuilo undo`. Se ignora a sí mismo en Git.

<Aside type="tip">
Sin una terminal, por ejemplo en un script, cuilo no pregunta. Imprime el plan, no cambia nada y sale con el código 2. Pasa `--yes` para aplicar sin preguntar.
</Aside>

## Mira lo que cuilo rastrea

<Steps>

1. Revisa los archivos generados:

   ```sh
   cuilo status
   ```

   ```text
   clean     src/ui/atoms/status-badge/index.ts
   clean     src/ui/atoms/status-badge/status-badge.module.css
   clean     src/ui/atoms/status-badge/status-badge.tsx
   ```

2. Edita la línea 5 de `status-badge.tsx` para agregar un tono:

   ```tsx
   export type StatusBadgeTone = "neutral" | "accent" | "success";
   ```

3. Revisa otra vez. El archivo editado ahora aparece como `modified`:

   ```sh
   cuilo status
   ```

   ```text
   clean     src/ui/atoms/status-badge/index.ts
   clean     src/ui/atoms/status-badge/status-badge.module.css
   modified  src/ui/atoms/status-badge/status-badge.tsx
   ```

4. Pregunta de dónde viene una línea, con `path:line`:

   ```sh
   cuilo why src/ui/atoms/status-badge/status-badge.tsx:5
   cuilo why src/ui/atoms/status-badge/status-badge.tsx:15
   ```

   ```text
   src/ui/atoms/status-badge/status-badge.tsx:5 is yours: added or changed since generation; ui 0.2.0 piece `atom`
   src/ui/atoms/status-badge/status-badge.tsx:15 is from the pack (line 15 of the original); ui 0.2.0 piece `atom`
   ```

</Steps>

Este registro es lo que hace seguras las actualizaciones. Cuando el pack `ui` publica una versión nueva, `cuilo update ui` la fusiona con tu archivo editado en vez de sobrescribir tu línea. Consulta [Actualiza el código generado](/es-mx/guides/updates/).

## Mira el historial y deshaz

<Steps>

1. Lista las transacciones que puedes deshacer:

   ```sh
   cuilo log
   ```

   ```text
      1  add ui/atom  (3 file(s))
   ```

2. Deshaz la última:

   ```sh
   cuilo undo
   ```

   ```text
   error: these files changed after transaction 1; undo with force to discard the edits: src/ui/atoms/status-badge/status-badge.tsx
   ```

   cuilo se niega, porque deshacerla tiraría tu cambio en la línea 5.

3. Deja la línea 5 como estaba y vuelve a correr `cuilo undo`. O descarta el cambio con `--force`:

   ```sh
   cuilo undo --force
   ```

   ```text
   Undid transaction 1: add ui/atom
   ```

4. Revisa que no quede nada:

   ```sh
   cuilo status
   ```

   ```text
   Nothing generated yet.
   ```

</Steps>

La transacción creó `cuilo.lock`, así que al deshacerla también se borró el lockfile. Solo quedan `package.json` y `.cuilo/`.
